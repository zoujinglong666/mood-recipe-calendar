# 会员分级与配额设计

## 规则

普通用户每天可创建 3 次基础菜谱推荐，会员每天 20 次。普通用户每个自然周可手动生成 1 次简单周菜单；会员不限次数。锅仔多轮智能体、重排和替换仅对有效会员开放。

## 服务端

新增按 `openid + feature + period_start` 唯一的配额计数表和服务。推荐任务创建、周菜单生成和智能体接口在业务执行前由服务端授权；任务失败时归还推荐配额。所有周期按 Asia/Shanghai 计算。

配额接口返回会员状态、每项上限、已用、剩余和重置时间。前端仅展示该接口结果，不能自行计数。

## 前端

首页和菜谱页显示当日推荐余量，触顶时弹出会员引导。普通用户访问锅仔智能体显示权益拦截，不调用智能体接口；周菜单页仍允许每周一次手动简单生成。会员页展示明确的 20 次每日推荐、智能体不限次和无限周菜单权益。

## 安全与降级

后端为唯一权限来源。会员到期立即按普通用户配额处理。前端配额读取失败时不阻止入口，但实际请求仍会被后端拒绝；请求返回配额错误后显示同一会员拦截。
