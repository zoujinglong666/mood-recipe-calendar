# 做菜智能体知识资料交付说明

后续可以直接把资料发给 Codex，不需要先整理成数据库格式。支持 Markdown、TXT、CSV/Excel、Word、PDF，以及权威网页链接清单。

每批资料最好同时说明：

- 来源名称与原始链接或出版信息
- 适用菜品、食材或技法
- 是否已由你或厨师审核
- 版本或发布日期
- 哪些内容允许直接教用户，哪些仅供内部参考

入库时每个知识块至少保留以下字段：

```csv
title,content,category,keywords,source_name,source_url,source_version,reviewed_at,enabled
肉类熟度判断,知识正文,FOOD_SAFETY,"熟透,中心温度,温度计",来源名称,https://example.com,2026-09,2026-09-17,1
```

处理规则：一条知识只讲一个可独立检索的问题；不得删除原始出处；缺少来源或审核信息的内容不启用；相互冲突的资料不自动合并，先标记等待确认。

建议分批顺序：食品安全 → 基础刀工与火候 → 常见失败补救 → 食材替换 → 具体菜系和菜谱。每批 20～100 条最容易审核和回归。
