# 锅仔小程序上架前人工核对清单

> 代码内的自动防护已落地；以下项目必须在正式 AppID、生产域名和真机环境中人工确认。

## 微信公众平台

- [ ] 服务类目与菜谱推荐、AI 对话、虚拟权益完全一致。
- [ ] 用户隐私保护指引与小程序隐私页逐项一致，含注销、个性化开关和第三方处理者。
- [ ] request、uploadFile、downloadFile 合法域名均为 HTTPS，证书有效且无重定向。
- [ ] 内容安全接口权限已开通，生产环境 `WECHAT_CONTENT_SAFETY_ENABLED=true`。
- [ ] 消息推送 Token/AES Key、虚拟支付 OfferID/AppKey 与回调 URL 已正确配置。
- [ ] 道具 `GZHY_30D` 价格为 ¥9.90，有效期 30 天，非自动续费；`YDHC_1124` 与画册权益一致。
- [ ] 客服入口真实可用，退款、未到账和投诉处理路径可达。
- [ ] 主体备案、小程序备案及涉及的算法/生成式 AI 备案状态符合当前上线地区要求。

## 凭据轮换

- [ ] 轮换微信 AppSecret、消息 Token/AES Key 和虚拟支付 AppKey。
- [ ] 轮换 MySQL 密码、COS SecretId/SecretKey、AI API Key 和 session_key 加密密钥。
- [ ] 新密钥只进生产密钥管理/环境变量，旧密钥已在各平台失效。
- [ ] 运行 `scripts/check-no-secrets.ps1`，结果为“凭据扫描通过”。

## 真机回归

- [ ] 拒绝隐私授权后仍可访问免授权页，受保护功能不会偷偷收集数据。
- [ ] 关闭个性化后不读写长期记忆；单条删除、全部清空和注销后重登录均验证。
- [ ] AI 菜谱页、分享卡和月度画册上均有可见 AI 标识。
- [ ] 违规文字、违规图片和内容安全服务故障均会被阻断，不会落库或进入分享。
- [ ] 注销后会话立即失效，私有数据删除，订单去标识化，COS 图片队列最终清空。
- [ ] 支付取消、失败、弱网、未到账、重复回调和跨账号查单全部验收，同一订单只发一次权益。
