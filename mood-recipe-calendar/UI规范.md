# 心情菜谱日历 · 前端 UI 规范

> 版本：V1.0 · 基于 PRD V3.0 配色系统 + 20 张高保真设计稿提炼
> 适用：uni-app (Vue3) 前端，所有页面/组件必须遵循本规范

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| 治愈暖色 | 全局以暖米白为底，蜜桃/暖陶红为强调，拒绝冷色和高饱和 |
| 圆角柔和 | 所有容器大圆角（24~50rpx），无尖锐棱角 |
| 锅仔贯穿 | 每个页面至少出现一次锅仔（插画或表情），作为情感锚点 |
| 留白充足 | 页面横向 padding 32rpx，区块间距 24~32rpx |
| 轻阴影 | 卡片/按钮使用低透明度暖色阴影，不用重黑阴影 |
| 可交互优先 | 所有视觉元素必须可点击/有反馈，禁止纯装饰整图替代页面 |

## 四、间距 · 圆角 · 阴影

### 4.1 间距刻度（8 的倍数）

| 级别 | 值 | CSS 变量 | 用途 |
|------|-----|----------|------|
| 大 | 32rpx | `--mrc-space-lg` | 页面横向 padding、大区块间距 |
| 中 | 24rpx | `--mrc-space-md` | 卡片内 padding、中间距 |
| 小 | 16rpx | `--mrc-space-sm` | 元素间距、小 gap |

### 4.2 圆角

| 级别 | 值 | CSS 变量 | 用途 |
|------|-----|----------|------|
| 大卡片 | 24rpx | `--mrc-radius-lg` | 页面卡片、日历卡 |
| 小卡片 | 16rpx | `--mrc-radius-md` | 标签、小容器 |
| 胶囊 | 50rpx | `--mrc-radius-pill` | 按钮、功能条、标签 |

### 4.3 阴影

| 类型 | 值 | 用途 |
|------|-----|------|
| 卡片阴影 | `0 6rpx 16rpx rgba(90,62,43,0.08)` | 普通卡片 |
| 按钮阴影 | `0 8rpx 20rpx rgba(255,158,110,0.35)` | 主按钮 |
| 悬浮条阴影 | `0 10rpx 30rpx rgba(90,62,43,0.16)` | 底部固定操作条 |

## 五、组件规范

### 5.1 按钮

#### 主按钮（蜜桃渐变胶囊）
- 类名：`.mrc-btn-primary`
- 高度：96rpx，圆角 50rpx
- 背景：`linear-gradient(135deg, #FFB88C, #FF9E6E)`
- 文字：白色 32rpx 600
- 阴影：`0 8rpx 20rpx rgba(255,158,110,0.35)`
- 按下：`scale(0.97)` + 阴影减弱

#### 次按钮（描边胶囊）
- 类名：`.mrc-btn-outline`
- 白底 + 2rpx 蜜桃描边，暖陶红文字
- 按下：背景 `#fff7f0`

#### 大 CTA 按钮（首页今日幸运菜）
- 渐变胶囊，内部分两行：主标题 38rpx 700 + 副标 22rpx 白色 92%
- padding 40rpx 0，圆角 50rpx

### 5.2 卡片

- 类名：`.mrc-card`
- 背景：`--mrc-bg-card`（奶油杏）
- 圆角：24rpx
- padding：24rpx
- 阴影：`0 6rpx 16rpx rgba(90,62,43,0.08)`

### 5.3 标签 Chip

- 类名：`.mrc-tag`
- 奶油杏底，圆角胶囊，padding 6rpx 20rpx，20rpx 文字
- 强调态：`.mrc-tag--accent`（暖陶红 15% 透明底 + 暖陶红文字）

### 5.4 功能条（首页双区）

- 奶油杏底，圆角 40rpx，overflow hidden
- 左右两区等分，中间 2rpx 淡杏分隔线
- 每区：图标 34rpx + 文字 26rpx 500，padding 30rpx 0
- 按下：背景 `rgba(255,255,255,0.6)`

### 5.5 日历

- 7 列网格（周日~周六），gap 4rpx
- 周标题：18rpx 浅褐
- 日期格：20rpx 暖褐，圆角 8rpx
- 今日：暖陶红 18% 底 + 2rpx 暖陶红边框 + 暖陶红粗体数字
- 本周小卡（周一起）：30% 宽度，与月历并排

### 5.6 输入框

- 白底，圆角 16rpx，padding 20rpx 24rpx
- 边框 2rpx `--mrc-border`，聚焦时变 `--mrc-accent`
- 文字 28rpx 暖褐，placeholder 浅褐

### 6.3 使用规范

- **引用方式**：`<image src="/static/guozai/mood_01_happy.png" mode="aspectFit" />`
- **不要拉伸**：始终用 `aspectFit`，容器设正方形
- **心情联动**：用户选择心情后，页面锅仔切换为对应 `mood_0X_*.png`
- **页面匹配**：每个页面优先使用对应动作锅仔（见上表"用途"列）
- **装饰元素**：锅仔旁可加小星星✨、小云朵☁️、小爱心❤️作为点缀（CSS 或 emoji）

## 七、页面布局规范

### 7.1 页面骨架

```
页面（.mrc-page）
├── 导航栏（AppNav：标题居中 + 右侧锅仔）
├── 内容区（padding 0 32rpx）
│   ├── 锅仔 hero / 插画区
│   ├── 主操作按钮
│   ├── 功能卡片
│   └── ...
└── 底部安全区（padding-bottom + env(safe-area-inset-bottom)）
```

### 7.2 导航栏

- 自定义导航栏（`navigationStyle: custom`）
- 标题居中 32rpx 600 暖褐
- 右侧锅仔（64rpx，开心表情），点击进个人主页
- 左侧：非首页显示返回按钮（白底圆形）

### 7.3 底部安全区

- 所有页面 `padding-bottom: calc(48rpx + env(safe-area-inset-bottom))`
- 固定底部操作条：`bottom: calc(16rpx + env(safe-area-inset-bottom))`

## 八、图标与装饰

|------|------|
| 功能图标 | 使用 emoji（🎲📷📝❤️📖📊）或锅仔插画，不用 SVG 图标库 |

| 气泡 | 白色圆角气泡 + 小三角指向锅仔，用于锅仔说话 |

## 九、交互反馈

|------|------|
