## Why

“我的”页设置按钮当前误跳到隐私政策，用户资料编辑、主题配置和账号退出也分散在不同位置；尤其把外观设置放在“关于我们”中不符合用户预期。需要新增一个职责清晰的设置页，统一承接个人资料、主题和登录状态管理。

## What Changes

- 新增独立“设置”页面，并将“我的”页右上角设置按钮改为进入该页面。
- 将头像、昵称和当前登录状态集中到“用户基本信息”区域；资料编辑复用现有上传和用户更新接口。
- 将“跟随系统 / 浅色 / 深色”和主题色配置从“关于我们”迁移到设置页，复用现有主题状态与 CSS 变量。
- 增加带二次确认、进行中状态、失败恢复和明确完成反馈的“退出登录”操作；退出后清理本地会话并停留在设置页的未登录状态，后续主动进入需要身份的功能时仍可按现有机制重新登录。
- 精简“我的”页资料区域为展示与设置入口，避免两处同时编辑；“关于我们”只保留品牌、产品说明和服务信息。
- 设置页延展锅仔 IP，但保持工具页应有的克制、清晰与可访问性；适配深色模式、安全区、微信小程序和 H5。

## Capabilities

### New Capabilities

- `settings-experience`: 定义设置页入口、用户基本信息编辑、主题配置迁移和退出登录的完整交互行为。

### Modified Capabilities

无。

## Impact

- 前端页面：新增 `src/pages/settings/index.vue`，调整 `src/pages/profile/index.vue` 与 `src/pages/about/index.vue`。
- 前端状态与接口：复用 `src/stores/user.ts`、`src/store/manualThemeStore.ts`、`src/composables/useManualTheme.ts`、`src/api/auth.ts` 和现有上传能力，不增加依赖。
- 路由：由页面生成机制注册 `settings` 页面；不手工维护生成产物。
- 后端/API：不新增接口，继续使用既有用户资料更新和退出登录接口。
- 跨端：微信小程序使用现有头像选择和昵称能力；H5 提供等价的可操作资料表单，不调用微信专属 API。
- 验收标准：设置入口正确可达；资料修改后设置页与“我的”页同步；主题即时生效并持久化；“关于我们”不再出现主题设置；取消退出不改变会话，确认退出成功后设置页显示未登录状态，失败时保留登录状态且可重试。

### Goals

- 为账号与外观偏好提供唯一、符合认知的管理入口。
- 消除资料编辑和主题设置的重复入口，并让退出登录形成可信闭环。

### Non-goals

- 不改造登录协议、用户注销、数据导出或隐私政策流程。
- 不新增主题引擎、第三方组件或后端数据结构。
- 不在本变更中重做“我的”页之外的业务页面。
