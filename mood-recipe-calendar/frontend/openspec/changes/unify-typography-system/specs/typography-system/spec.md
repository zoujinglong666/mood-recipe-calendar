## Purpose

为所有业务页面提供统一、无需下载的跨端字体基础，使 H5 与微信小程序中的标题、正文、标签和表单文字保持清晰且层级一致。

## ADDED Requirements

### Requirement: 页面使用统一系统字体
系统 SHALL 让业务页面和可输入控件继承同一套跨端系统无衬线字体，并在首选字体不可用时提供可读回退。

#### Scenario: 跨端打开页面
- **WHEN** 用户在 H5 或微信小程序打开任一业务页面
- **THEN** 页面正文、标题和表单文字使用同一字体体系且无需等待网络字体加载

### Requirement: 字重层级跨端可预测
系统 SHALL 使用常规、强调和重标题等受支持的标准字重表达信息层级，不使用跨端表现不稳定的非标准字重值。

#### Scenario: 查看不同层级文字
- **WHEN** 页面同时展示正文、标签和重要标题
- **THEN** 用户能通过一致的标准字重区分层级，且 H5 与微信小程序不会因非标准超粗字重产生明显差异
