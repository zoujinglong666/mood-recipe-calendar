## Purpose

让用户将健身或轻盈减脂等饮食方向交给锅仔记住，并在每次推荐时获得符合目标、但不替代健康或医疗建议的菜品倾向。

## ADDED Requirements

### Requirement: 用户可以保存饮食目标

系统 SHALL 允许用户在锅仔记忆中选择保持均衡、健身增肌或轻盈减脂之一，并将该选择与现有口味偏好一同保存、修改和清除。

#### Scenario: 保存健身目标

- **WHEN** 用户在锅仔记忆中选择健身增肌并保存
- **THEN** 系统保存该目标，并向用户说明锅仔会优先考虑营养均衡、优质蛋白和适量主食的套餐倾向

#### Scenario: 保存减脂目标

- **WHEN** 用户在锅仔记忆中选择轻盈减脂并保存
- **THEN** 系统保存该目标，并向用户说明锅仔会优先考虑蔬菜、优质蛋白和少油烹饪的套餐倾向

#### Scenario: 清除健康目标

- **WHEN** 用户清除锅仔记忆或选择保持均衡
- **THEN** 后续推荐不再以健身或减脂目标作为额外偏好

### Requirement: 健康目标影响推荐解释

系统 SHALL 将已保存的饮食目标用于推荐上下文和推荐理由；当目标未设置时 MUST 保持原有口味与心情推荐行为。

#### Scenario: 有目标的推荐

- **WHEN** 用户已保存健身增肌或轻盈减脂目标并请求推荐
- **THEN** 推荐结果或锅仔解释会说明该菜与目标的相关倾向，同时继续遵守用户的过敏和忌口

#### Scenario: 旧用户继续使用

- **WHEN** 没有保存健康目标的用户请求推荐
- **THEN** 系统提供原有推荐体验，不要求用户先补充健康信息
